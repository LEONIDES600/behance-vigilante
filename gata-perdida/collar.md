# Collar de papel — versión corta

> Escríbelo en un collar de papel/tira de papel enrollada (o una tira de washi/tape
> ancho) y ponlo **flojo** al cuello de la gata (regla de 2 dedos: deben caber 2
> dedos entre collar y cuello). Objetivo: que su dueño —o quien la alimente— vea
> que **alguien la está buscando** y te contacte. Papel = seguro, se rompe si se
> engancha.

## Cara A (NL) — la que se lee primero
```
BEN IK VAN JOU? Bel a.u.b.
📞 【tu teléfono】
```

## Cara B (EN)
```
AM I YOURS? Please call
📞 【tu teléfono】
```

## Versión ultra-corta (si el espacio es mínimo)
```
Baasje? Bel 📞【teléfono】
```

## Variante "¿tiene dueño?" (para saber si alguien más la cuida)
```
Heb ik een baasje? Bel me a.u.b. 📞【teléfono】
Do I have an owner? Please call.
```

**Tips:**
- Rotulador permanente e impermeable; refuerza el papel con cinta transparente por fuera.
- No aprietes: collar flojo, de papel, que ceda.
- Escribe el número **dos veces** (por si se borra un lado).
- Si en 1–2 días alguien llama diciendo que la cuida, ya tienes el hilo hacia el dueño.
